## 编译运行

所有示例均为标准 C，用 gcc 直接编译即可：

```bash
gcc code.c -o code && ./code
```

Windows（MinGW）下：

```bat
gcc code.c -o code.exe && code.exe
```

## 每日自动同步

仓库根目录的 `sync.bat` 用于一键把本机新增/修改的内容推送到 GitHub：

- **手动**：双击 `sync.bat`
- **自动**：已注册 Windows 计划任务 `DSA-Daily-Sync`，每天 21:00 自动执行（无改动则跳过）

详细用法见 [同步说明](#同步说明)。

---

### 同步说明

脚本做的事（按顺序）：

1. `git add -A` —— 收录所有新增/修改/删除的文件
2. 无改动则直接退出，不产生空提交
3. `git commit -m "auto-sync YYYY-MM-DD HH:MM:SS"`
4. `git pull --rebase` —— 先合并远端（比如你在别的电脑上改过），避免冲突
5. `git push` —— 推送到 GitHub

日志文件写在 `.git/sync-log.txt`（不在工作区里，不会被提交）。

手动运行且想自定义提交信息时，可在该目录打开终端执行：

```bash
git add -A && git commit -m "你的提交信息" && git pull --rebase && git push
```
